K. Durga Reddy — Data Analytics Portfolio

HOW TO VIEW
1. Extract the ZIP file.
2. Open the durga_portfolio folder.
3. Open index.html in Chrome or another browser.

FILES
- index.html: the portfolio website
- profile.png: your uploaded photo
- resume.pdf: your resume
- Four project PDFs: linked from the project cards

LINKEDIN / GITHUB
The buttons are placeholders. To add links later, open index.html in a text editor and replace the two placeholder <a> tags in the Professional Links section with your profile URLs.

PUBLISH ONLINE
Upload the extracted folder to a static website host. Keep index.html, profile.png, resume.pdf, and the four project PDFs together so the links continue to work.
