# K. Durga Reddy — Data Analytics Portfolio

A responsive, single-page portfolio built with HTML and CSS, ready for GitHub Pages.

## Files
- `index.html` — website
- `assets/profile.png` — optional profile photo
- `assets/resume.pdf` — optional resume PDF
- `assets/sales-project.pdf` — optional sales project PDF
- `assets/customer-project.pdf` — optional customer project PDF
- `assets/student-project.pdf` — optional student project PDF

## Personalize before publishing
1. Add your photo to `assets/profile.png` (or leave the initials fallback).
2. Add your resume as `assets/resume.pdf`.
3. Add project PDFs using the exact filenames above, or update the links in `index.html`.
4. Replace `your.email@example.com` and the LinkedIn link with your real contact details.
5. Review the education dates and every skill/project description so they accurately reflect your experience.

## Publish with GitHub Pages
1. Create a **new public repository** on GitHub (for example `durga-data-analytics-portfolio`).
2. Upload `index.html`, `README.md`, and the `assets` folder. Make sure `index.html` is in the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then click **Save**.
6. Wait for deployment, then open the exact URL shown under **Your site is live at**. A project site URL includes the repository name at the end.

This template uses no build tools or external libraries.
